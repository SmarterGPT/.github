# SmarterGPT

Open-source tooling for bounded, inspectable AI agents.

Founded by **[Joseph Gustavson (Guffawaffle)](https://github.com/Guffawaffle)**.
SmarterGPT brings together tools for continuity, capability discovery, policy,
behavioral constraints, and explicit orchestration.

## Explore the framework

| Project | Responsibility | Source |
| --- | --- | --- |
| AXF | Capability discovery and curated session-start and handoff surfaces | [AXF](https://github.com/Guffawaffle/axf) |
| Lex | Continuity, frames, policy, and workspace storage | [Lex](https://github.com/Guffawaffle/lex) |
| Lex MCP | MCP access to Lex | [Lex MCP](https://github.com/Guffawaffle/lex-mcp) |
| LexRunner | Explicit plans, gates, receipts, eligibility, and merge execution | [LexRunner](https://github.com/Guffawaffle/lexrunner) |
| LexSona | Visible behavioral constraints | [LexSona](https://github.com/Guffawaffle/lexsona) |

These projects have public source and packages in the
[`@smartergpt` npm scope](https://www.npmjs.com/org/smartergpt).
The source links above remain the current homes while the organization transition
is prepared. Existing package names stay the same.

**ContextForge** is being developed as a non-authorizing context-linking library;
it has no public package or source repository yet. **LexThority** is
[historical research](https://github.com/Guffawaffle/lexthority), with no active
product commitment.

## Contribute and use

Start with [smartergpt.dev](https://smartergpt.dev), then follow the relevant
repository's README, contribution guidance, and release instructions. Open an
issue in the project that owns the behavior before proposing a broad change.

Project licenses and notices govern each repository and release. Preserve Joseph
Gustavson's founder attribution and the applicable contributor and third-party
notices. Attribution does not add restrictions to those licenses.

Repository access and GitHub membership do not grant runtime policy authority.
Verification, enrollment, and execution require their own explicit trust and
authorization boundaries.
